حاسبة القروض العربية - نسخة تجريبية أولية

المحتويات:
- index.html: التطبيق.
- manifest.json و icon.svg: تعريف التطبيق وأيقونته.
- sw.js: التخزين المؤقت للعمل دون إنترنت بعد أول زيارة.

مهم:
1) افتح index.html في المتصفح للتجربة الأولية، لكن تثبيت PWA والعمل دون إنترنت عبر Service Worker يتطلب استضافة HTTPS.
2) ارفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة مثل GitHub Pages أو Netlify.
3) افتح رابط الموقع في Safari على iPhone، ثم زر المشاركة > إضافة إلى الشاشة الرئيسية.
4) افتح التطبيق مرة واحدة مع الإنترنت لتخزين الملفات، ثم جرّب وضع الطيران.
5) هذه نسخة أولية للحسابات التقديرية، وليست معتمدة بنكيًا. يجب التحقق من قواعد الفائدة والزيادة السنوية مع عقد القرض قبل الاستخدام المهني.
